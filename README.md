## House Price Prediction Using Machine Learning

### Objective
Predict house prices based on property features using Python and machine learning.

### Features Used
- House size (sqft)
- Number of bedrooms and bathrooms
- Age of the house
- Distance to city center

### Tools & Techniques
- Python, Pandas, NumPy
- Exploratory Data Analysis
- Linear Regression
- Model Evaluation

### Outcome
Built a regression model to estimate housing prices and identify key price drivers.
